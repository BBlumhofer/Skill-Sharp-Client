Type: task

Blocked by: 04

## Question

Ein Workflow `.github/workflows/ci.yml` läuft bei Push und PR auf `ubuntu-latest`: .NET 8 und 10,
Python 3.12 und opensmi-server in fester Version (Commit von `main`, als Variable), dann
`dotnet test` für beide Targets mit `OPENSMI_SERVER_DIR` auf `examples/dummy`. Linux reicht vorerst
(Entscheidung des Nutzers).

## Answer

`.github/workflows/ci.yml` angelegt: Push und PR auf `ubuntu-latest`, .NET 8.0.x und 10.0.x,
Python 3.12, opensmi-server per Checkout auf Commit `OPENSMI_SERVER_REF` (voller SHA, weil
`actions/checkout` keinen Kurz-SHA nimmt) und `pip install`, dann `dotnet test` mit
`OPENSMI_SERVER_DIR` auf `examples/dummy`. TRX-Ergebnisse werden bei Fehlschlag hochgeladen.
Die Testhelfer sind plattformneutral (`python`, `Kill(entireProcessTree)`, `Path.Combine`), keine
Änderung nötig. Ungeprüft: erster echter Lauf auf GitHub.
