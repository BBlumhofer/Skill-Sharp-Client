Blocked by: 04

## Question

A workflow `.github/workflows/ci.yml` runs on push and PR on `ubuntu-latest`: .NET 8 and 10,
Python 3.12 and opensmi-server at a fixed version (a commit of `main`, as a variable), then
`dotnet test` for both targets with `OPENSMI_SERVER_DIR` pointing at `examples/dummy`. Linux is enough for now
(the user's decision).

## Answer

Created `.github/workflows/ci.yml`: push and PR on `ubuntu-latest`, .NET 8.0.x and 10.0.x,
Python 3.12, opensmi-server via checkout at commit `OPENSMI_SERVER_REF` (full SHA, because
`actions/checkout` does not accept a short SHA) and `pip install`, then `dotnet test` with
`OPENSMI_SERVER_DIR` pointing at `examples/dummy`. TRX results are uploaded on failure.
The test helpers are platform-neutral (`python`, `Kill(entireProcessTree)`, `Path.Combine`), no
change needed. Unverified: the first real run on GitHub.
